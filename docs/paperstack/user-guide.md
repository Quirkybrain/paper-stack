## 1. 打开文档与欢迎页

无文档打开时显示欢迎页：标题「打开一份文档。」、按钮「打开文件」「打开目录」、说明
「直接读取本地文件，不移动、不修改原文」，以及**最近阅读**列表和**内置示例**卡片。

- **打开文件**：`Ctrl+O` 或工具栏「打开」→「打开文件」；支持 `.md` 与 `.markdown`（UTF-8，含 BOM）。
  取消选择器不会改变页面、选区或焦点。
- **打开目录**：`Ctrl+Shift+O` 或「打开目录」；建立授权根后可在文件树中浏览目录。
- **最近阅读**：首屏最多 6 条（文件名、最短区别父目录、相对时间），更多条目滚动查看；不可用条目标注
  「原文件不可用」；「移除」只移除列表项，不删除源文件。
- **内置示例**：无最近记录时提供，可离线阅读。
- **命令行打开**：`paperstack <文件>`；应用已运行时，新进程退出（exit 0），文件移交既有窗口以新标签打开
  （单实例行为）。
- **批量打开**：按输入顺序逐项处理，首个成功项激活；单个失败单独提示，不清空已成功项。

只读保证：阅读不写入、不移动、不改名源文件（AT04 前后哈希/目录快照一致）；复选框等交互控件在阅读视图中
不可修改原文。

> 未验证：拖放打开、真实 IME 组合输入（见 known-limitations）。

## 2. 标签与多文档

- 标签栏仅在**存在 2 个及以上文档**时显示；再次打开同一文件会激活已有标签并保持其展示版本。
- 同名不同目录的文档显示最短区别父目录；悬浮或键盘聚焦可查看完整路径。
- `Ctrl+W` 关闭当前文档（不询问保存）；关闭当前标签后按**最近使用（MRU）→ 右邻 → 左邻**激活；
  关闭最后一个标签回到欢迎页（不退出应用）。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 切换下一个/上一个标签；标签过多时用「所有标签」入口，不缩小到不可点击。
- 正文中的文档链接默认**当前标签导航**；`Ctrl+点击`/中键请求新标签并复用已有目标标签。
- 每个标签各自维护阅读历史与搜索会话，互不串用。

## 3. 文件树与大纲

左侧导航区（工具栏「导航面板」或 `Ctrl+B`）包含互斥的两个面板：**文件**与**大纲**；同一时间只显示一个。
打开检查抽屉时导航临时收起，关闭后恢复原选择。

**文件树**

- 目录箭头与目录行均可展开/收起；文件行单击立即打开。
- 只把本版支持的文档作为主要可打开项；其余文件可用「显示其他文件」查看，点击不支持类型会给出说明
  （「本版不支持打开此类型文件。」）。
- 键盘：上/下移动焦点，左收起/回父项，右展开/进子项，Enter 打开；焦点与已打开文件的选择状态分离。
- 异常状态逐行标注：无权限、超出授权范围、符号链接指向授权范围之外、已缺失；节点加载失败保留原树并提供
  「重试」，空目录显示「此目录为空。」，条目过多时说明仅显示部分条目。

**大纲**

- 按文档标题层级生成；正文滚动驱动当前章节高亮，不抢焦点、不强制展开已收起的节点。
- 重复标题带序号区分（如「Duplicate 标题 (1)/(2)」），点击可跳转到对应的一处。
- 点击大纲先记录来源，再跳转；配合 `Alt+←` 可返回。

## 4. 页内搜索

`Ctrl+F` 或工具栏「查找」打开搜索条（焦点进入输入框）：范围「正文/源码」、输入框、「区分大小写」、
当前/总数计数、上一项、下一项、关闭。

- **输入法（IME）**：组合输入期间不提交查询、不更新计数、Enter 不作定位；组合结束后按约 150ms 去抖计算。
  `Ctrl+B`/`Ctrl+F`/`Ctrl+W` 等全局快捷键在组合输入中不拦截。
- **Enter / Shift+Enter**：尚未选择命中时分别跳到第一项/最后一项；已有选择时分别跳到下一项/上一项。
  命中循环，跨越首尾时提示「已回到第一项/最后一项」。也可用「上一项/下一项」按钮。
- **状态**：索引未就绪显示「正在建立全文索引」（保留查询文字）；无结果提示「未在当前正文中找到」并可
  切换到源码查找；公式源码命中标注「公式源码匹配」并提供检查入口。
- **折叠内容**：折叠代码块/未显示块命中时会先展开再定位，并保持展开；搜索与复制覆盖全部内容，不受折叠
  显示影响。
- **范围**：正文范围覆盖可读文本、代码、图片替代文本与公式源码；源码范围针对**当前展示版本**的解码原文，
  不读取磁盘上的新版本。v0.1.0 没有目录全文搜索、正则/拼音/语义查询。
- **会话与返回**：打开搜索条记录来源锚点；第一次显式定位才建立历史项；`Esc` 关闭搜索条并保留最后命中位置，
  `Alt+←` 回到搜索前位置。查询仅保存在内存中，不写磁盘；切换标签保留该标签的查询与索引状态。

> 已验证：AT17（大小写 3/1 命中、折叠命中）、AT24（键盘查找、200% 缩放）、IT07（键盘链）。
> 记录观察：自动化合成输入下搜索框内 Return 不推进命中（「下一项」按钮正常）；见 known-limitations。

## 5. 只读源码视图

- 更多菜单 →「查看源码」切换到源码视图（按钮随后变为「返回阅读」）；顶部明确标注「源码 · 只读」，带行号，
  文本可选择但不可编辑，不提供保存入口。
- 源码与正文**共用展示版本**；存在待更新版本时两者都显示「有新版本」标记，切换视图不等于更新。
- 进入源码时优先把当前正文块映射到源码行；返回阅读时优先映射当前源码位置，失败则回到最近保存的锚点并
  提示「未能精确定位，已返回最近位置」。
- **大文档（>50 MiB）**：源码以分段窗口显示，状态行显示「已显示第 {start}–{end} 行，共 {total} 行」；
  搜索扫描不完整时会单独说明（不得当作完整扫描）。

## 6. 公式、代码、图表与图片

### 6.1 公式

公式不会因选中而弹出抽屉；通过显式按钮/键盘焦点/内容菜单进入：

- **查看源码**：抽屉依次显示公式、公式源码（不含 `$` 分隔符）、来源章节与诊断（可折叠）；需要完整原文可
  进入源码视图。
- **复制源码**：仅在系统剪贴板确认成功后显示「已复制」并在约 1.5 秒后恢复；失败持续显示
  「复制失败，请重试或手动选择文本。」。
- **放大**：进入放大层查看。
- 公式错误（未知宏等）**按块回退**显示可读回退，不影响其余内容；目标在更新后消失时回到最近正文位置并
  提示来源变化。

### 6.2 代码块

代码块操作条包含「复制」「换行」「展开全部 N 行 / 收起」「查看源码」（文档源码，无运行按钮）：

- 复制获取**整块字面代码**：去掉围栏与行号、保留缩进与尾换行、逻辑换行 LF 归一；折叠状态下也复制全部内容
  （已验证 450 B/45 行与 29 B/49 B 等字节级载荷）。
- 长块默认显示前 20 行、可展开全部；换行只改变该块显示并记录当前会话偏好。
- 操作条在鼠标悬停与键盘聚焦时同样可达；屏幕阅读名称如「复制此代码块」。

### 6.3 图表（Mermaid）

- 图表在可见时渲染：支持流程图、时序图、类图；其余图种给出「本版支持流程图、时序图与类图」说明。
- 工具为「查看源码」与「放大」；错误或超限时保持块位占位（图种、引擎版本、错误摘要、定位范围），
  不影响正文其他内容。
- 图表渲染有节点数/时间限制；超限后可继续查看源码。正文滚轮始终滚动文档，只有打开放大层后才控制图表。

### 6.4 图片

图片适宽并保留比例；错误状态互相区分并给出可操作入口：

- 缺失：「找不到这张图片」+「查看相对路径」；
- 越界：「图片位于当前授权目录之外」+「选择允许的范围」；
- 远程未允许：「已阻止远程图片」+「了解连接范围」/「本次允许」；
- 超限/无法解码：说明大小或解码问题。

多张权限错误会汇总为一个资源提示，不逐图弹窗。GIF 仅显示静态首帧并在信息中说明。

### 6.5 放大层

放大层提供标题、关闭、缩小、放大、适宽、100%（重置）：滚轮平移内容，`Ctrl+滚轮` 缩放（带说明），
方向键可代替拖动；`Esc` 关闭并回到触发点。

## 7. 文档更新

应用会监视已打开文档的磁盘变化；当磁盘出现更新版本时，正文上方显示非模态横幅
「文件已有新版本。你正在阅读的内容未改变。」，文件名/标签旁出现「有新版本」标记。

- **现在更新**：提交到新版本并提示结果：「已更新，已保持阅读位置」（精确）或「已更新，位置近似恢复」
  （近似，不会把近似伪装成精确）。
- **稍后**：横幅折叠为「有新版本」条，标记保留；点击可再次展开。
- 连续多个新版本会**合并为最新候选**，不堆叠横幅；处理 v2 时又观察到 v3，旧候选失效、界面不回退。
- **更新模式**（设置 →「文件与更新」）：
  - 「保持当前阅读」（默认）：等待你确认更新；
  - 「跟随最新版本」：文档在前台且没有选区或检查操作时自动更新；有选区/检查层时暂存并提示
    「为保留选中文本，已暂停自动更新。」/「为保留当前操作，已暂停自动更新。」；后台标签暂存，激活后再评估。
  - 有选区仍主动更新时，按钮明确写作「更新并清除选区」。
- **源文件不可用**（被移动/删除）：保留已加载内容并提示「找不到原文件。保留了已加载内容，但它可能不是最新
  版本。」，提供「重新定位 / 重试 / 关闭标签」；重新定位同一文件恢复原身份，内容不同时先说明「将按新版本
  处理，位置可能只能近似恢复」再采用。
- 位置或偏好保存失败不影响正文可读，只提示「本次阅读位置可能无法保存。」等状态。

## 8. 设置

### Aa 浮层（快速显示设置）

工具栏「显示设置（Aa）」打开非模态浮层：正文字号（14–24px）、行距（1.5–2.2）、正文宽度（560–960px）、
主题（跟随系统/浅色/深色）、「恢复显示默认」。更改立即预览并保持阅读锚点；数值越界提示
「数值超出范围，已保留上一个有效值。」；没有「应用」按钮。

### 完整设置（`Ctrl+,`）

模态对话框，左侧分类：**阅读 / 文件与更新 / 语法 / 隐私 / 关于**。

- **阅读**：字号、行距、宽度、主题、启动时恢复上次阅读；全局持久。
- **文件与更新**：新文档默认更新行为（保持当前阅读/跟随最新版本）+ 当前文档覆盖（仅本次文档会话有效）。
- **语法**：技术文档（默认）/ 标准 Markdown；「行内美元公式」开关（关闭后 `$…$` 按原文显示，`$$` 块公式
  不受影响）。切换会重新渲染当前展示版本，不加载磁盘较新内容。
- **隐私**：见下一节。
- **关于**：版本、所属者、「GNU GPL v3.0（GPL-3.0-only）」、许可证/第三方声明离线查看、构建信息与
  「获取对应源码」（当前显示「未配置对应源码入口；公开发行前必须补齐。」）。

保存失败时提示「本次已生效，但未能保存到本地」并提供重试（不会假装已保存）；「恢复显示默认」只重置显示
字段，不影响记录、权限、更新与语法覆盖。

## 9. 隐私与数据清除

- **记住阅读记录**：关闭后停止写入最近、位置与会话记录（已有记录需另行清除）。
- **清除已有记录**：选择类别（最近阅读、位置与会话、缓存、授权、诊断日志），显示当前数量/空间；
  默认**不预选**；确认按钮写明动作（如「清除 12 条最近记录」）。
- 结果**逐类报告**（「已清除 N 项」/「部分类别未能清除，请查看各项结果。」）；清除授权与「撤销」效果一致；
  清除后停止对应类别的写回，直到显式重新打开或恢复记录（已验证：清除后退出重启不自动重建）。
- 「清除操作不会删除原始文档。」；卸载应用不会自动删除用户数据目录。
- **持久授权**：列表显示已记住的授权，可「撤销」；撤销后停止新的读取并提示「授权已被撤销，已停止新的读取。」。
- **诊断日志**：显示当前用量与上限；日志仅保存在本机，不上传。

## 10. 授权对话框

本地资源与远程图片都**默认阻止**，只有你主动允许后才读取：

- **本地资源范围授权**（模态）：越界资源先聚合提示一次（不逐图弹窗）。对话框显示规范化范围、资源数量、
  「只用于读取此目录中的关联资源，不会写入你的原文件。」；按钮「允许本次读取」/「保持阻止」；
  复选框「记住此目录授权」**默认不勾选**（勾选后下次启动仍可访问）。焦点进入安全默认操作，`Esc` 等同
  「保持阻止」，关闭后焦点回到触发控件；拒绝后保留占位与正文，只有再次主动点击才会重新打开。
- **远程图片授权**（模态）：「加载将连接以下图片服务器」列出目标**域名**（不默认暴露带令牌的完整 URL）；
  按钮「本次文档允许加载」/「保持阻止」；仅对当前文档会话生效，关闭文档、撤销或退出后失效；
  重定向到未确认地址会被阻止。允许后图片真实渲染且缓存到本机。
- **撤销**：停止新的读取、取消在途请求、卸载远程资源并回到阻止占位。
- 注意：受 Tauri scope 机制限制，撤销后**同一进程内**再次打开同一路径的图片会保持阻止直到重启
  （安全优先的超额阻止，见 known-limitations）。

## 11. 诊断与导出

出现读取/渲染错误时，就近显示可理解的一句话原因（如「无法读取这个文件」）与「诊断」入口：

- 诊断面板：错误类别、文档展示版本、源位置、重试/继续路径；「详细技术信息」默认折叠；未知错误给出
  错误编号。
- **复制诊断摘要**：默认不包含正文、私人绝对路径或 URL 令牌。
- **导出诊断**：「导出诊断」→ 预览（默认脱敏，显示「已脱敏 N 处」；可显式勾选包含源码上下文/完整路径并在
  预览中查看）→ 选择保存位置 → 若目标是受保护源文件/源目录会拒绝（「该位置是受保护的源文件或源目录，
  请另选位置。」）→ 已存在文件需确认覆盖 → 按实际结果提示。选择器取消不写文件；保存失败保留预览供手动
  复制；不上传、不自动重试到其他路径。

## 12. 大文档阅读

打开较大或较复杂文档时，应用会先询问处理方式：

- **阈值提示**：文件大于 10 MiB 或复杂度超预算时，对话框「大文档阅读」提供三个选项：
  - **简化阅读**：保留全文文本与基础结构；公式、图表等重型内容显示源码；**搜索与复制完整可用**；
  - **只读源码**：以可控方式显示解码文本，可查找与复制，不做重型渲染；
  - **取消**：文档不打开，回到欢迎页。
- **>50 MiB**：不进行全量渲染，直接进入只读源码分段窗口，并说明「文件超过本版全量处理上限，可用源码
  分段查看。」；状态行说明已显示/已扫描范围。
- **简化阅读的说明**：工具栏显示「简化阅读」徽标与「已显示范围与全文索引范围将分别说明。」横幅。
  为保证流畅，简化阅读只挂载**有界窗口**的正文块：未挂载的块不渲染 DOM，但全文仍进入搜索索引，可通过
  搜索结果、大纲或页内锚点跳转定位；滚动会按步替换窗口。这是有意的降级模式（阈值语义见 known-limitations）。

> 已验证：AT29（11 MiB 对话框/简化阅读/尾搜/复制/CPU 回落/WM 关闭；52 MiB 源码窗口）、IT07（同场景）。

## 13. 键盘快捷键

| 快捷键 | 动作 | 说明/例外 |
|---|---|---|
| `Ctrl+O` | 打开文件 | 系统选择器；取消回触发位置 |
| `Ctrl+Shift+O` | 打开目录 | 明确授权根 |
| `Ctrl+F` | 页内查找 | 有文档可搜时；不用于目录全文搜索 |
| `Enter` / `Shift+Enter` | 下一项 / 上一项 | 仅搜索输入焦点且非输入法组合状态（未选择时分别跳第一/最后一项） |
| `Alt+←` / `Alt+→` | 后退 / 前进 | 活动标签历史；无历史时不产生动作 |
| `Ctrl+W` | 关闭当前文档 | 无保存询问；单标签仍可关闭 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 | 各自历史不变 |
| `Ctrl+B` | 导航区显示/收起 | 输入法组合中不拦截；菜单有同等入口 |
| `Ctrl+,` | 打开设置 | 焦点进入设置对话框 |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 正文增大/减小/重置字号 | 输入框不吞字符 |
| `Esc` | 关闭最上层临时区域 | 系统选择器 → 模态对话框 → 放大覆盖层 → 非模态检查抽屉 → 搜索条；不退出应用 |

## 14. 可访问性

- **焦点顺序**：跳到正文入口 → 工具栏 → 标签 → 当前导航 → 正文 → 活动辅助区；提供「跳到正文」
  （SkipLink）与正文 landmark。
- **模态对话框**：焦点限制在对话框内，初始焦点落在安全默认操作（授权＝保持阻止；清除＝取消）；关闭后回到
  触发元素；`Esc` 只关最上层，不退出应用。
- **非模态区域**（抽屉、Aa 浮层、搜索条、更新横幅）不困住焦点，可 Tab 离开，`Esc` 关闭并回触发点。
- 状态不只靠颜色表达（文字标签 + 图标）；禁用按钮给出原因（tooltip 与 `aria-describedby`）；图标按钮有
  可读名称；成功/错误提示不抢焦点。
- 目标为**适用 WCAG 2.2 AA**（对比度、键盘、回流、200% 文字缩放、非颜色唯一表达）；**是设计目标，不是
  认证**。200% 缩放下阅读/搜索/大纲已抽查通过；完整任务链与真实 IME 未验证。
